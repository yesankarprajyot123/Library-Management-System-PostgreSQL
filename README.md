# 📚 Library Management System using PostgreSQL

A complete Library Management System built using PostgreSQL that demonstrates database design, SQL programming, and real-world library operations.

This project was developed to practice SQL concepts from beginner to intermediate level while solving real-world business problems.

---

## 🚀 Project Overview

This project manages:

- Books
- Members
- Employees
- Branches
- Book Issue Records
- Book Return Records

The project includes SQL queries, reports, CTAS, and stored procedures using PostgreSQL.

## ▶️ How to Run

1. Install PostgreSQL.
2. Open pgAdmin.
3. Create a database.
4. Run `TABLE INFO.sql`.
5. Run `Library Management Project File 1.sql`.
6. Run `Library Management Project File 2.sql`.
7. Execute the SQL queries and stored procedures.
